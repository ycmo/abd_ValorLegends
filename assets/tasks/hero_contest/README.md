# 勇者角逐

從活動主畫面執行，目標是贏到 4 次獎勵，最多打 8 場。每場前會檢查底部挑戰次數是否為 0；若為 0 就停止。若連續失敗 2 場，回主畫面後按一次刷新，成本 5 紅鑽。

戰鬥結果頁的「點擊繼續」有時會跳到其他活動頁，所以每場結束後若沒有明確回到勇者角逐主畫面，會只執行 `AwayFromKeyboard/route_screenshots/勇者角逐/02_勇者角逐_swipeV.png` 這個 route 步驟，從目前活動左側選單直接切回勇者角逐大廳，再判斷勝利次數或剩餘挑戰次數。

目前尚未接入每日任務列表掃描；若要放入 run-all，需要補每日任務列的 `task_label.png`。
