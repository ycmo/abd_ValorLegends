# Ads Collections

Offline proposal-collection outputs live here.

The first pilot is named `close_x_proposal_collection_pilot_*` because it primarily uses close template, close glyph, and geometry-X proposal sources. It is not a complete seven-family detector evaluation.

Collection outputs keep raw proposals, NMS candidates, overflow records, parent screenshots, raw bbox crops, expanded context crops, overlays, and manifests for later GUI review.
